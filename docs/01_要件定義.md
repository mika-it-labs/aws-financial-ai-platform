# 要件定義

## 1. システム概要

金融系企業の社内業務システムを想定し、
AWS上にWebアプリケーション基盤を構築する。

## 2. 利用者

社内ユーザー

## 3. 必要機能

- Webアクセス
- PostgreSQLデータベース
- ファイル保存
- システム監視
- 障害通知
- バックアップ
- AIによる社内文書検索

## 4. 非機能要件

### 可用性
複数AZ構成を採用する。

### セキュリティ
DBをインターネットから直接アクセスできない構成とする。

### 監視
AWSリソースをDatadogで監視する。

### バックアップ
RDSのバックアップを設定する。

### コスト
検証環境として必要な時間のみリソースを起動する。
