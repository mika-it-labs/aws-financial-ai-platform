## 2. Subnet

### Public Subnet

CIDR:
10.0.1.0/24

用途:
ALB等のインターネット公開が必要なリソースを配置する。

### Private Subnet

CIDR:
10.0.11.0/24

用途:
EC2やRDS等、直接インターネット公開しないリソースを配置する。
