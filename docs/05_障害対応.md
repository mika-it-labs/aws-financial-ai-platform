# HTTP通信障害対応記録

## 1. 障害概要
EC2上のApacheで公開しているWebページに、外部ブラウザからアクセスできない状態を再現した。

## 2. 障害発生方法
セキュリティグループのインバウンドHTTP（TCP 80）ルールを一時的に削除した。

## 3. 確認結果
- ブラウザ：アクセス失敗
- Apache：active
- EC2内部のcurl：HTTP 200 OK

## 4. 原因
HTTP 80のインバウンド許可ルールが存在しなかったため。

## 5. 復旧対応
HTTP / TCP 80 / 0.0.0.0/0 のルールを再追加した。

## 6. 復旧確認
ブラウザでHello World!の再表示を確認した。

## 7. 再発防止策
セキュリティグループの変更前後に通信確認を実施し、変更内容と復旧手順を記録する。
