# 「AWS金融系システムを想定したインフラ基盤・監視・AI活用環境の設計構築」

## 概要

金融系システムを想定したAWS基盤を個人学習として構築する。

AWS基盤の設計・構築、監視、障害対応、
運用設計、AI/RAG活用までを段階的に検証する。

## 目的

- AWSネットワーク設計を理解する
- AWS基盤構築を経験する
- Datadogによる監視を経験する
- 障害対応を経験する
- TerraformによるIaCを経験する
- AI/RAGをAWS基盤へ組み込む

## 使用予定技術

- AWS
- VPC
- EC2
- ALB
- RDS PostgreSQL
- S3
- IAM
- Datadog
- Terraform
- AI / RAG
